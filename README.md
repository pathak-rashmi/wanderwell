# WanderWell Planner

You are an award-winning UI/UX designer and senior frontend developer. Design and build a modern, premium, responsive frontend-only Travel Planner website that looks like a real-world SaaS application. The website should have exceptional UI/UX, smooth animations, glassmorphism effects, modern gradients, rounded cards, subtle shadows, and a clean minimal design. The website should be fully responsive for desktop, tablet, and mobile.

The goal of the website is to solve the problem of scattered travel planning by allowing users to organize every part of their trip in one place.

Use HTML, CSS, JavaScript (or React + Tailwind CSS if supported). Focus entirely on frontend with mock data only. Do not implement backend functionality.

DESIGN REQUIREMENTS

---------------------------------------------------

The UI should resemble modern SaaS products like Airbnb, Notion, Stripe, Linear, and Apple in terms of cleanliness and spacing.

Use:

• Glassmorphism

• Soft gradients

• Rounded corners (16–20px)

• Blur effects

• Hover animations

• Consistent spacing

• High-quality travel images

• Responsive grids

• Elegant typography

• Premium cards

• Smooth transitions

• Professional icons

The website should feel like a product that could genuinely be launched, not a college assignment.

Ensure accessibility with proper contrast, keyboard navigation, and semantic HTML.

Generate a polished, production-quality frontend with clean, modular code and reusable components.
